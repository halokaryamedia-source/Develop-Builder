# Develop-Builder

Develop-Builder is the source preset for a **general development governance and continuity kernel**. It exists to make project development safe and resumable without turning simple work into a complicated process.

Development authority: **`Local`**.

## Core principle

> Use the shortest correct path with sufficient context and sufficient proof.

The preset standardizes how work is routed, grounded, owned, continued, verified, and stopped. It does not prescribe a product architecture, framework, runtime, database, release model, provider system, or source-tree layout.

## Core Bootstrap

The day-zero baseline contains only the responsibilities needed before non-trivial development:

```text
README.md
AGENTS.md
GITHUB_RULES.md
CONTEXT.md
.gitignore
.agents/skills/development-brief/SKILL.md
docs/foundation/01-project-overview.md
docs/foundation/02-product-requirements.md
docs/knowledge/next-action.md
```

Additional routing maps, ownership indexes, decision logs, workspace systems, experiments, specialists, CI, release workflows, and runtime structure are added only when a real project responsibility earns them.

## Navigation

## Evidence boundary

Repository/source inspection proves repository/source claims. Hosted CI proves only what it actually executes. Runtime, device, visual, audio, model, target-machine, and human-acceptance claims require their matching evidence.
